Интернет-магазин (учебный проект) 
FastAPI, PostgreSQL, SQLAlchemy, Alembic, Pydantic, JWT
— Реализовал REST API для интернет-магазина с поддержкой CRUD-операций над сущностями: пользователи, категории товаров, продукты.
— Разделил логику на 4 модульных роутера: auth, permissions, categories, products — для лучшей читаемости и масштабируемости.
— Настроил подключение к PostgreSQL через SQLAlchemy (ORM-подход), написал модели данных и связи между ними.
— Управление схемой БД: создал и применил миграции с помощью Alembic.
— Обеспечил валидацию входных данных и сериализацию ответов с помощью Pydantic-моделей.
— Реализовал систему аутентификации: вход по логину/паролю + выдача JWT-токена; защита эндпоинтов по ролям (админ / пользователь).
